**要闻（5 条）**

**1. FTC 据报道对 OpenAI、Anthropic 与 METR 立案：CID 将在数周内发出**  
9 月 30 日路透社引 FTC 高级官员：委员会正对 Anthropic、OpenAI 及其他实验室做行业调查，查产品对消费者的潜在危险；计划发正式信息索取（civil investigative demands，类似传票），并强制高管作证，对象含独立评测组织 **METR**。官员称主席 Andrew Ferguson 在 Hugging Face 侵入前已有顾虑，侵入后紧迫性上升；这是特朗普任内针对 rogue agent 的首次执法动作，法律依据是 FTC 法下的不公平/欺骗性商业行为。彭博、华盛顿邮报同日核实：索取预计数周内发出。Ferguson 上周在路透社活动上称应先用现有法律、对行业「求监管」持深怀疑。OpenAI、Anthropic、METR 均未立即置评。标「据报道 / 待 FTC 公开 CID」。对合规/采购，这是把「白宫自愿协议次日」与「现有消费者保护法」写成并行轨道；合同现在可以问评测报告、事故通知与 METR 类第三方调查材料是否会进监管卷宗。  
来源：Reuters https://www.reuters.com/business/ftc-opens-probe-into-ai-giants-including-anthropic-openai-new-york-post-reports-2026-09-30/ · Washington Post https://www.washingtonpost.com/technology/2026/09/30/ftc-launches-broad-investigation-into-anthropic-openai/ · Bloomberg https://www.bloomberg.com/news/articles/2026-09-30/ftc-probing-openai-and-anthropic-over-product-safety-concerns

**2. Google 发布 Gemini 4 Argon：DeepSWE 77.9%，先给 Fairwind 网络防御方**  
同日 Google DeepMind 上线新一代前沿模型 **Gemini 4 Argon**，定位真实软件工程、法律/金融知识工作与网络防御。厂方：DeepSWE v1.1 **77.9%**（GPT-6 Astra 74.1%、Claude Opus 5.5 74.2%）；Vals Index **68.9%**；CWE-bench v1 与 Astra 并列 **68%**；输出上限从 64K 提到 **100 万** token。导入价每百万 token **2 / 10 美元**（缓存读入再打 95% 折），导入期结束后为 **4 / 20 美元**。现已通过 Fairwind Program 向受信任网络防御方滚动；厂方称对这批用户及内部团队将**关掉 cyber 护栏**，以便做漏洞发现、验证与补丁。Wiz Scan for Good 早期演示：Argon 在医院软件里找到此前前沿模型漏掉的敏感信息暴露。面向开发者/企业/消费者的开放「尽快」，起点是付费 API 与 Google AI Ultra 订阅；同时称在走美国政府自愿预发布流程。对路由/安全工程，这是把「先给防御方、后给大众」写成可采购的档位；合同现在可以问 Fairwind 是否等于无护栏出货、以及 1M 输出在账单上如何封顶。  
来源：Google https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/ · Google DeepMind https://deepmind.google/models/gemini/

**3. DeepSeek 开源昇腾工具链：TileLang 等六件套对齐 NVIDIA 侧组件**  
同日 DeepSeek 官微宣布，开源面向华为昇腾的编程与通信基础设施，与此前给 NVIDIA 平台的组件一一对应。六件套：TileLang（昇腾 950 后端，原生代码生成/自动调度/同步）、DeepGEMM-Ascend、DeepEP-Ascend、TileKernels、FlashMLA、DeepSelect。GitHub `TileKernels` 同日更新：Ascend 950 NPU、CANN **9.2.0** 及以上，运行时自动选 NVIDIA / 昇腾后端。DeepSeek：华为「毫无保留」支持，双方共同推进 **128** 卡昇腾 950 超节点的计算与通信优化；称 TileLang 编程模型比 CUDA 更简单，并已承载 V4 训练里大部分算子。路透社、南华早报、IT之家交叉核对。对训练/推理工程，这是把「CUDA 之外的第二条 kernel 路径」写成可 clone 的仓库；下一轮对账的是 128 卡超节点上的真实 MFU，以及同一套 Python API 在 NVIDIA 与昇腾之间的数值一致性。  
来源：Reuters https://www.reuters.com/world/asia-pacific/deepseek-partners-with-huawei-develop-chip-programming-tools-reducing-reliance-2026-09-30/ · GitHub https://github.com/deepseek-ai/TileKernels · IT之家 https://www.ithome.com/1/008/604.htm

**4. Micron 财年营收 1,331.9 亿美元：HBM 长约承诺升至 320 亿，下季指引 615 亿**  
同日 Micron 发布截至 9 月 3 日的 2026 财年四季报：四季营收 **542.3** 亿美元（上年同期 113.2 亿），全年 **1,331.9** 亿美元（上年 373.8 亿）；GAAP 全年净利 849.7 亿美元。路透社：长期供货协议（LTSA）客户承诺从 6 月的 **220** 亿美元升至 **320** 亿美元，多数为现金定金；CFO Mark Murphy 称剩余履约义务约 **1,500** 亿美元（上季约 1,000 亿）。下季（2027 财年一季）指引营收 **615 ± 15** 亿美元，分析师原预期约 570 亿；CEO Sanjay Mehrotra 称 2027、2028 财年存储供需将比 2026 更紧。对采购/产能，这是把「HBM 已从现货变成预付长约」写成可进董事会材料的数字；下一轮对账的是 2027 日历年 HBM bit 是否已被订完，以及定金条款在需求回落时能否退。  
来源：Micron https://investors.micron.com/quarterly-results · Reuters https://www.reuters.com/business/micron-forecasts-quarterly-revenue-above-estimates-2026-09-30/

**5. ElevenLabs 员工要约估值 220 亿美元：语音 agent 周对话量 1,500 万**  
同日 ElevenLabs 官宣完成 **3 亿美元**员工股权要约，估值 **220 亿美元**，为 2 月 D 轮（募 5 亿、估值 110 亿）的两倍。带队为 Wellington 与 T. Rowe Price；新进投资者含 EQT、Goldman Sachs、GIC、OTPP、Sapphire Ventures、BDT & MSD。厂方：企业已占收入 **55%**；ElevenAgents 每周处理逾 **1,500 万** 次对话，约为 2 月的三倍，覆盖退款、续保、预约等；模型覆盖 90 多种语言。路透社、TechCrunch 核实。这是二次流通、不是向公司注资的新一轮。对语音/客服采购，这是把「语音 agent 已进大型险企与电信日常运维」写成可对账的用量；合同现在可以问多渠道会话的审计日志与人工接管时延，而不是一份估值等于产品已过合规门槛。
