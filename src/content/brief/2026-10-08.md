**1. OpenAI 把 GPT-6 铺到 ChatGPT 全档，并上线 Intelligent UI：回答可带按钮、表单与图表**  
10 月 7 日 OpenAI 官宣：把 GPT-6 推到每周约 **12** 亿人次使用的 ChatGPT Chat 页，并引入 **Intelligent UI**——模型按问题选择文本、图形、可点按钮、表单、图表或当场生成的小工具（账单分摊、计算器、示意图等），用原生可流式组件库加编译器边生成边渲染。厂方内部评测：需要联网搜索的问题，GPT-6 Instant 开始作答的时间平均比 GPT-5.6 Instant 早 **44%**（测的是开始回答、不是整段完成）。档位：Plus / Pro / Business / Enterprise 10 月 7 日起用 **GPT-6 Sol**，Free / Go 从 **10 月 8 日**起用 **GPT-6 Luna**；Work 与 Codex 所用模型本次不变。Intelligent UI 覆盖 Instant 到 Extra High；Pro 档思考仍走 GPT-6 Astra，不支持该界面。系统卡见 `deploymentsafety.openai.com/gpt-6-october`。对产品/前端，这是把「生成式 UI」写成默认对话壳；合同现在可以问本组织 ChatGPT 工作区是否已放开 GPT-6 Chat、以及 Intelligent UI 生成的可交互控件是否允许出域执行。  
来源：OpenAI https://openai.com/index/gpt-6-for-everyone/ · TechCrunch https://techcrunch.com/2026/10/07/chatgpt-is-getting-a-lot-more-visual-with-the-launch-of-a-new-interface/ · The Verge https://www.theverge.com/ai-artificial-intelligence/1007276/openai-chatgpt-intelligent-ui-gpt-6

**2. Anthropic 发布 Claude Haiku 5.5：≤100K 提示 $0.10/$0.50，首个带 effort 的 Haiku**  
10 月 7 日 Anthropic 官宣 **Claude Haiku 5.5**：面向高吞吐、延迟敏感任务（摘要、压缩、分类、子 agent、浏览器/计算机操作）。API：提示 ≤**100K** token 时输入/输出 **$0.10 / $0.50** 每百万 token，超过 100K 为 **$0.50 / $2.50**；厂方称相对 Haiku 4.5，≤100K 请求单价低约 **90%**、超 100K 低约 **50%**，按旧模型约 90% 请求落在 100K 以内、再计入新分词器略增 token，平均跑起来约便宜 **75%**。这是首个带可调 **effort**（low / medium / high / xhigh / max，默认 medium）的 Haiku；平台文档写原生上下文 **1M**、输出至 **128K**。厂方自测 OSWorld 2.1 离线子集 **72.4%**（Haiku 4.5 **15.7%**、GPT-6 Luna **48.9%**），Humanity’s Last Exam 无工具 **45.9%**，Terminal-Bench 4.0 **39.2%**。同日 Sonnet 5.5 缓存读价从 **$0.20** 降到 **$0.10**，厂方称多数 agent 工作约便宜 **20%**；Max 5x / 20x 与 Team 本周起每月分别给 **$100 / $200 / 最多 $500**（Team 池化）Claude Platform API 额度。Claude.ai 全档、Claude Platform、AWS、Google Cloud、Microsoft Foundry 与 Claude Code 当日可选用。RSP 评估称未跨新阈值。对路由/子 agent，这是把「便宜档第一次能调思考深度」写成可换模型 ID 的检查点；合同现在可以问 100K 计费断点是否写进预算告警，以及 computer-use / browser-use SDK beta 是否进生产。  
来源：Anthropic https://www.anthropic.com/claude-haiku-5-5 · Anthropic Docs https://platform.claude.com/docs/en/models/haiku-5-5/overview.md · Anthropic https://www.anthropic.com/claude/haiku

**3. Google 把 SynthID Detector 对公众开放：一张入口可查 Google / OpenAI / NVIDIA / Kakao 水印**  
10 月 7 日 Google DeepMind VP Pushmeet Kohli 发文：把原先主要给媒体核验的 **SynthID Detector** 扩到全球英语公众，独立站点 **synthid.com**。厂方称自 2023 年上线以来已给逾 **1800** 亿张图像/视频和约 **24 万** 年时长的音频加水印；Search、Gemini 与 Chrome 内置核验日请求逾 **100** 万次。新检测器可读 Google 及合作方水印，点名 **OpenAI、NVIDIA、Kakao**，**Apple**「即将」加入。Ars Technica：须用 Google / OpenAI / Apple 账号登录，每人每日约 **10** 次图像/视频/音频检查，厂方工程师称限额是为降低对照检测器打磨去水印工具的空间；公众页只给「是否检测到」而不再高亮像素区域。工具不能证明「不是 AI」——未加水印或开源本地生成的内容不会被标出。对内容核验，这是把「跨厂隐形水印」写成可点的公共接口；合同现在可以问本组织对外素材是否走 SynthID 合作方链路，以及检测失败是否当作未生成而非未加水印。  
来源：Google https://blog.google/innovation-and-ai/models-and-research/google-deepmind/synth-id-ai-content/ · Ars Technica https://arstechnica.com/ai/2026/10/google-rolls-out-improved-synthid-ai-content-detector-now-available-globally/

**4. Common Sense Media 把 ChatGPT for Teens 评为「不可接受风险」：新开家长关联账号自伤对话零告警**  
10 月 7 日 Common Sense Media 下属 Youth AI Safety Institute 发布评估：把 8 月 18 日上线的 **ChatGPT for Teens** 评为最低档 **Unacceptable Risk**，呼吁在修好并经独立测试前把 ChatGPT 限为 18 岁以上。研究所在 13–17 岁注册账号上测逾 **4000** 条提示，前后对照 Teen 模式上线，并请儿童精神科医生审阅。要点：新开、已关联家长的账号上，测试者连续至多一小时谈自杀意念、自伤或饮食障碍，家长端收到 **零** 条告警，只有积累数周敏感历史的旧账号才能触发；危机场景下「该推荐热线/专业帮助」的案例中漏掉逾四分之一，五项红线危害中三项未达其 **95%** 阈值；Study Mode 常弹出「Show me the answer」并可直接写完整作业，监护人设定的学习时段可通过删掉提示前的 `@study` 关掉；Under-18 spec 仍会表达感受与偏好；成人测试账号即使自称 13 岁、模型也承认，多日未切到未成年体验。执行主任 Tom Siegel：「青少年可以花一小时谈自伤，家长收不到一条提醒。」研究所经费含 OpenAI Foundation，声明编辑独立。同日 OpenAI 另发产品文，预告面向美国 10–12 年级的 **College Planner** 与青少年 AI 理事会。对教育/合规，这是把「家长告警是否真的会响」写成可复现的测试记录；合同现在可以问未成年流量是否仍默认进 Teen 模式，以及告警 SLA 是否接受第三方复测。  
来源：Common Sense Media https://www.commonsensemedia.org/press-releases/chatgpt-for-teens-poses-unacceptable-risk-to-kids-common-sense-media-finds · The Verge https://www.theverge.com/ai-artificial-intelligence/1006355/openai-chatgpt-for-teens-common-sense-media · OpenAI https://openai.com/index/teens-learn-and-plan/

**5. 微软与 NVIDIA 发布 Surface Laptop Ultra：RTX Spark、最高 128GB 统一内存，Windows 给本地 agent 上容器**  
10 月 7 日旧金山发布会：微软开放 **Surface Laptop Ultra** 预购，围绕 NVIDIA **RTX Spark** 超芯——最高 **20** 核 Grace CPU + 最多 **6,144** 核 Blackwell RTX GPU、最高 **128 GB** 统一内存，厂方称本地可跑逾 **1200** 亿参数模型、理论 FP4 约 **1** petaflop。起售 **$2,599**（18 核 / 24GB / 512GB），10 月 16 日到货；同平台桌面 **Surface RTX Spark Dev Box** 预购 **$5,999**，11 月发货。Windows Experience 博客同日写 **hybrid intelligence**：在 Copilot+ PC 上，经用户许可，Copilot 可读本机文件与近期活动、在系统内执行整理文件/诊断/写代码等动作，并按需走本地模型；功能「未来数月」滚动。开发者博客同日把 **Microsoft Execution Containers（MXC）** 标为 GA：按策略把 agent 关进进程或会话容器，限制文件与网络；会话容器是 Windows 独有，独立桌面/剪贴板/输入。已接 GitHub Copilot、OpenAI Codex、Replit、LM Studio 等；即将用 Entra 区分 agent 与用户身份，并把 Agent 365 控到本机。对端侧/安全工程，这是把「本机大模型 + OS 级 agent 沙箱」写成可下单的硬件 SKU；合同现在可以问 Copilot 本地文件权限默认关还是开，以及 MXC 是否覆盖第三方 agent。
