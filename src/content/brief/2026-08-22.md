**要闻（5 条）**

**1. DeepSeek 上线 V4-Flash-Vision-Exp，多模态 Agent API 按 V4-Flash 计价**  
8 月 21 日，DeepSeek 在 API 平台开放实验性视觉模型 `deepseek-v4-flash-vision-exp`：官方称纯文本 Agent / 推理 / 世界知识与 V4-Flash 持平，需视觉理解的 Agent 基准相对文本版大幅跃升，并自称接近 Anthropic Opus-4.8。图片按 token 计费、单图最多 384 tokens，价格与 V4-Flash 相同；支持 Chat Completions、Messages、Responses，以及 base64、URL 与免费 Files API。同步发布的 DeepSeek Harness 0.1.1 已内置该模型。对工程侧意味着截图、图表与前端还原类 Agent 可走低价多模态接口，无需另接视觉专用模型。  
来源：DeepSeek API Docs https://api-docs.deepseek.com/news/news260821 · THE DECODER https://the-decoder.com/deepseek-releases-experimental-flash-vision-model-that-rivals-opus-4-8-on-agent-benchmarks/ · 凤凰网科技 https://tech.ifeng.com/c/8vm2SSvIFte

**2. OpenAI 将 GPT-5.6 Sol 开发者价格下调逾 20%，为期约三个月**  
8 月 21 日，OpenAI 在 GPT-5.6 产品页更新：旗舰 Sol 的 API 与积分定价下调逾 20%，为期三个月。路透社对照其价目表：标准短上下文输入由每百万 token 5 美元降至 4 美元，输出由 30 美元降至 20 美元；覆盖 API，并滚动到 ChatGPT Work 积分与 Codex；Pro / Plus / Business 订阅价不变。这是 7 月 30 日 Luna 降 80%、Terra 降 20% 之后，同一家族第三次调价。对已在生产环境调用 Sol 的团队，账单会直接下降，无需改代码。  
来源：OpenAI https://openai.com/index/gpt-5-6/ · Reuters https://www.reuters.com/technology/openai-cuts-developer-pricing-frontier-gpt-56-sol-model-by-more-than-20-2026-08-21/

**3. 据报道 Anthropic 投行向潜在投资者勾勒逾 1000 亿美元 IPO、约 2 万亿美元估值**  
8 月 21 日，《纽约时报》援引知情人士称，Anthropic 的投行已向潜在投资者表示，此次 IPO 可能募资逾 1000 亿美元、估值约 2 万亿美元，将超过 SpaceX 6 月创下的募资纪录。多家后续报道称公司 6 月已秘密递交 S-1，公开申报或最早本月底、上市或最早 10 月；7 月底年化营收 run rate 报逾 650 亿美元，二季度营收报约 115 亿美元。公司本身尚未公开给出估值、日期或代码。数字均属投行沟通与媒体转述，标「据报道」。若落地，将直接改写前沿实验室的融资与自研芯片预算上限。

**4. 据报道 NVIDIA 已通知大客户：明年出货的 AI 服务器系统涨价逾 15%**  
8 月 22 日，彭博社援引知情人士、路透转述：NVIDIA 部分最大客户已被告知，含其 AI 芯片的服务器系统在多数情况下将涨价逾 15%，主因内存成本飙升；涨价计划明年年初出货生效，覆盖 Vera Rubin 与 Grace Blackwell 等配置。官方尚未发布对等通稿。对规划 2027 集群的买家，TCO 假设需立刻上修，HBM / DRAM 供给仍是瓶颈。

**5. （8 月 19 日）Google 与 Marvell 扩大 TPU 配套定制芯片合作，并获约 122 亿美元认股权证**  
8 月 19 日（上溯约 72 小时）Marvell 监管文件披露：将为 Google 的 TPU 生态开发推理加速、存储 / 网络 / 内存接口控制器及近存计算等定制硅；同时向 Google 发行最多约 5897 万股认股权证，行权价 206.58 美元，全额行权约合 122 亿美元，可使 Google 成为其第五大股东。约 140 万股首年归属，其余按每 5 亿美元定制产品收入解锁一批，对应至 2033 财年累计采购或可达约 1200 亿美元（若目标兑现）。这是 Google 在 Broadcom 之外再嵌一条自研加速器供应链，也是又一例「采购挂钩股权」的循环融资结构。
