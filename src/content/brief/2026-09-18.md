**1. 华为 Connect：昇腾 960DT 提前三季到 2027 Q1；徐直军称中国模型「还感觉不到」美方前沿风险**  
9 月 17 日（周四）上海华为全联接大会开幕。副董事长、轮值董事长汪涛宣布：昇腾 **960DT**（训练）预计 **2027 年一季度**就绪，较原路线图提前 **三** 个季度；推理向 **960PR** 预计 **2027 年三季度**，提前 **一** 个季度。厂方称 960 系列算力按计划翻倍，并维持一年一代：970 在 **2028**、980 在 **2029**。同发业界首个采用近封装光学（NPO）的超节点 **Atlas 960E SuperPoD / 昇腾 960 超节点**：单超节点最多 **4096** 卡，通稿写 **8 EFLOPS** FP8、中文稿另写 **16 EFLOPS** FP4，HBM 容量最多约 **1 PB**；用 **5500** 个自研 Hi-ONE 光引擎替代传统约 **4.8 万**颗 800G 光模块，功耗降逾 **550 kW**，厂方称系统可用度 **99.8%**。多个超节点再组集群：二层 CLOS 四平面最多约 **51.2 万**卡，叠加多轨道拓扑最多 **100 万**卡。已部署超 **1000** 套 Atlas 900 A3 SuperPoD，Atlas 950 进入规模商用。软件侧：CANN 进入常态化开源社区，月活开发者超 **5200**、外部开发者占比 **61%**，超 **40** 个模型在昇腾上原生预训练，并成为 PyTorch 官网首个中国算力后端。轮值董事长徐直军对路透社：国内 AI 算力需求已经吃不满，「没有计划以全面铺开的方式进国际市场」；他「认为」昇腾在中国份额已超 NVIDIA，但**未提供数据**。同场徐直军把近一周美方「放缓前沿」写成能力差：美方实验室算力大，「也许只有他们自己知道模型到了哪一层」；「他们能感觉到的那类 AI 风险，中国这边的人或模型商也许感觉不到」——所以中国厂「也许需要把节奏加快到也能感觉到风险的水平」，同时「在推动发展和管理风险之间找平衡」。这不是新权重，也不是已经量产的 960 硅片：对锁国产训练栈的人，下一轮对账的是 960DT 能否在 2027 Q1 真正进机柜、CANN 生态能不能把 CUDA 工作流迁过来，以及「感觉不到前沿风险」会不会被读成继续满速扩卡，而不是一篇发布会等于已经替代 H100/Rubin。

**2. Anthropic 公开三套「前沿节奏」内部指标：Claude 已「主导」26% 的 AI R&D**  
同日，Anthropic Institute 发文，把 Amodei 上周六 *We Must Pace the Frontier* 里偏原则的「放缓」写成三套可复述的内部测量，并给了一份快照。**(1) R&D 自动化指数**：用 Epoch AI 的 Automation Level（AL0 无人参与 → AL5 全自主）。截至 **2026 年 8 月**：Claude 在所测 AI R&D 子集上**没有**全自主（AL5）；「主导」（AL4，高阶提示下端到端完成、人监督）占 **26%**；「协作」及以上（AL3+）超过 **90%**。CNA 转述路透社：该「主导」份额从 **3 月约 1%** 升到 8 月 26%。**(2) Agent 监督**：最常用内部平台上任一时刻约 **3 万**个做研究/工程的 agent；在线监控覆盖 **100%** 动作（通常数秒内、执行前可拦）；8 月分析逾 **10 亿**次决策，拦截率 **0.002%**（约 **1/47000**）；离线监控每周标出约 **10 万**条 transcript，最高优先级约 **50** 条进人工。**(3) 算力分配**：抽 **7 月 13–20 日**一周——进入 AI R&D 的算力约 **6%** 记为安全，进入「由 AI 驱动的 AI R&D」的约 **12%** 记为安全；厂方强调这是保守口径（能力与安全同等贡献的 token 不计入安全）。文中写明：若真按 Amodei 方案协调 pacing，这些数字预期会变；公司计划嵌入多家第三方评估员，权限对标内部风控。这是对近三日「自愿放缓 / 嵌入评估员 / OpenAI 错位披露框架」的**可核指标增量**：从 CEO 长文写成可点名的 AL 占比与安全算力份额，不是 Fable 停训。对运行侧，合同里现在可以要求「按同一套 AL / 监控覆盖率 / 安全算力占比定期披露」；同时也要预留「自研模型评自己、跨实验室尚无统一方法、6% 是一周快照不是年度预算」的分叉。

**3. Claude Code 重做 Projects：一个 coordinator 调度并行云端线程，关电脑后继续跑**  
同日产品博文 *Projects redesigned: from folder to conversation*。旧 Projects 是带知识库的文件夹式工作区；新版把「项目」收成一场持续对话：用户说目标，Claude 拆范围、委派并行 **thread**、审输出、组装结果，手机也可steer，关电脑后云端续跑。每个 thread 是一次独立的 Claude Code 云会话，自带分支和仓库副本；撞同一段代码按普通 PR 合并冲突处理。可再拆 subagent / loop / workflow。共享 memory 记住「发布改到周五、billing 动之前先问谁」；Library 收用户文件和 Claude 产物。例子：把结账 p75 延迟当目标，并行 profile 各 endpoint、试优化、开 PR；或一次接 API / web / mobile 三个仓，退役 v1 接口。Beta：**当天**面向「用 Claude Code 云会话、且 web/桌面还没有旧 Projects」的精选 Pro / Max；一周内扩到更多同档 Claude Code 用户，chat / Cowork / Team / Enterprise 随后。现有旧 Projects 暂不改。硬限制：线程只在云端，本地文件和内网「很快」才到；多线程都是完整会话，更容易撞用量上限。这不是新权重，而是把 Cursor Projects（9 月 10 日已覆盖）之后的「编排层」写成 Claude 侧可对账的 beta——对开发侧，自建 multi-agent 编码栈的人，下一轮对账的是「共享 memory + 每仓独立分支 + coordinator 合 PR」能不能替代自己写的 orchestrator，而不是一篇改版稿等于已经能在隔离网里跑。

**4. 《纽约时报》诉 OpenAI / 微软案解封：内部把训练写成「人类历史上最大规模的劳动盗窃」**  
同日，曼哈顿联邦法院解封《纽约时报》等原告简易判决动议中此前涂黑的段落（底层证据仍有密封）。路透社 / TechCrunch / Ars：微软应用科学总监 Brent Hecht 在 **2023 年 1 月**内部备忘录写，数百万人会把大模型「hoovering up」所有人的劳动看成「an astonishing theft of unprecedented proportions」，并写成或许是「the largest theft of labor in human history」；另有文件称大规模抓取新闻「完全嘲弄了合理使用」。Hecht **2024 年 1 月**内部材料把 Copilot「答案引擎」相对传统 Bing 搜索、时报站点点击率最多低约 **93%**（TechCrunch；TheWrap 写 87–93%）写成「doom loop」——「终端产品威胁其关键供应商的经济基础，这种情况很不寻常，但这正是我们给 LLM 内容供应链制造的局面」。ChatGPT 负责人 Nick Turley 内部写出版商面临「existential threat」，产品「largely substitutive」且「会越来越可替代」。OpenAI 总裁 Greg Brockman 把模型写成「excellent at news」；研究员 Nick Ryder 告知「绕过纽约时报付费墙的 hack」时，他回复「ah nice」。Nadella 宣誓：付费墙内容「任何人要用于 grounding 或训练都应当授权」；若当时知道 OpenAI 抓了付费墙，他会「要求 OpenAI 重训」；并同意与聊天机器人对话「已经替代了……必须回到原始站点」。微软发言人：Hecht「反映的是一名员工的个人观点，不是法律分析，不代表公司立场」；Nadella 证词与公司抗辩「完全一致」，「不应与法庭上的版权问题结论混为一谈」。OpenAI 当时未立即回应路透社。数字（原告首次公开）：OpenAI 中期训练数据里仅原告作品副本就超过 **91,692** 份；一份源自 Common Crawl 的数据集含逾 **200 万**份 nytimes.com 文档；Project Mango 训练集约 **160,903** 件原告独特作品。白宫已于 9 月 1 日向法官递交陈述，称训练「extraordinarily」具转换性。这不是新的侵权判决，而是把「合理使用 / 不替代原市场」抗辩写成可引用的内部原话与流量数字。对采购/数据侧，锁训练语料或出版授权的人，下一轮对账的是付费墙抓取、去版权声明、以及 Bing 点击漏斗，而不是一篇解封稿等于已经改写了合理使用标准。
