**要闻（6 条）**

**1. Anthropic 发布 Claude Opus 5.5：厂方称多数任务对标 Fable 5.1，典型负载较 Opus 5 便宜约 40%**  
9 月 22 日（周二，美西下午，北京时间已入 23 日）Anthropic 上线 Claude 5.5 家族首款 **Claude Opus 5.5**，自称「pace the frontier」呼吁之后的第一次发模型。近三日已写路透社知情人士「IPO 前再发一款」口径，本条是**官宣增量**。厂方：多数工作表现对标 Claude Fable 5.1；默认设置下典型负载成本较 Opus 5 低约 **40%**（价目本身输入/输出各降 **20%**，缓存读降 **60%**）。价目（每百万 token）：输入 **$4**、输出 **$20**、缓存读 **$0.20**、缓存写 **$5**；Fast 模式最高约 2.5 倍速度，**$8 / $40**。厂方自报 Terminal-Bench 4.0 **66.4%**（Fable 5.1 **55.8%**、Opus 5 **52.3%**、GPT-6 Astra **57.9%**，后一项转引 OpenAI）、CursorBench 4.0 **57.8%**（Fable 5.1 **51.8%**）；同时写明「这些分数与真实差距相比偏宽」。发布前经 Frontier Design、METR 等外部评测；厂方称自动化行为审计是迄今最强，但生物/网络能力接近 Mythos 5.1，因此沿用 Fable 5.1 级护栏，并开发生命科学 / 网络核验通道。API 名 `claude-opus-5-5`；Claude Pro / Max / Team / Enterprise 与 AWS、Google Cloud、Microsoft Foundry 当天可用。Sonnet 5.5、Haiku 5.5「未来数周」。对编码 agent 采购，这是把「Fable 级任务、Opus 级价目、缓存读腰斩」写成可对账的默认日常模型，而不是一篇发布稿等于已经替换 Fable 5.1。  
来源：Anthropic https://www.anthropic.com/claude-opus-5-5 · SiliconANGLE https://siliconangle.com/2026/09/22/anthropic-releases-claude-opus-5-5-and-openai-counters-with-two-cheaper-gpt-6-models/

**2. OpenAI 约 90 分钟后推出 GPT-6 Sol / Luna：API 较 GPT-5.6 促销价腰斩**  
同日约 90 分钟后（OpenAI 官方帖 18:12 UTC）OpenAI 把 GPT-6 家族扩到 Astra 之下的 **GPT-6 Sol** 与 **GPT-6 Luna**，自称沿用 Astra 的训练方法，把专业工作、事实性、编码、计算机使用与对齐下放到更快、更便宜的档位。价目（每百万 token，对照 GPT-5.6 促销价）：Sol 输入 **$4→$2**、输出 **$20→$10**；Luna 输入 **$0.20→$0.10**、输出 **$1.20→$0.50**，均为 **50%**。厂方自报 AutomationBench 上 Sol（xhigh）**33.2%**、每任务约 **$0.27**，称约为所列 Claude Opus 5（max，**26.9%**）每任务成本的 **9%**；DeepSWE v1.1 上 Sol（max）**68.8%**，距所列 Fable 5 最高分 **69.9%** 约 1.1 个百分点、每任务成本约低 **80%**。缓存读默认折扣 **90%**；GitHub 称过去数月未命中缓存的 prompt token 占比下降逾 **50%**。ChatGPT Work 与 Codex 向 Plus / Pro / Business / Enterprise / Edu 推出；Free / Go 可在桌面端试 Luna；API 名 `gpt-6-sol` / `gpt-6-luna`；**尚未**进 Chat。Astra 仍是厂方旗舰。对开发者，这是「中档模型按促销价腰斩」的路由增量：默认日常负载可先对账 Sol/Luna，把 Astra 留给最难的计算机使用与安全敏感任务。  
来源：OpenAI https://openai.com/index/introducing-gpt-6-sol-and-luna/ · TechCrunch https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/

**3. OpenAI 公布第三方评测「四块优先级 + 七条原则」：训练期即可介入，发布前可给修复窗口**  
同日 OpenAI 安全负责人 Lama Ahmad 博文 *Priorities and principles for effective third party assessments*，把 9 月 12 日 Altman「给独立评测者工位、工牌、发表权」与 9 月 21 日已覆盖的全球 RSI 标准提案收成可点名的评测文本，属**原则增量**。四块：**(1)** 覆盖训练 / 评测 / 内外部部署的 safety case；**(2)** 关键护栏（越狱、网络防御、错位监视器、能否被关掉）；**(3)** Preparedness 风险类别（化生、网络、自我改进）与错位评测是否饱和、阈值是否过时；**(4)** 关键错位事故的独立调查（点名 Hugging Face 事件）。七条原则含事先约定范围、相称访问、方法透明、利益冲突披露、保密、**发布前给实验室合理修复期**、以及实验室可申请 redact、评估方须标明实质性删节。官方只写「正在与多家第三方谈符合上述优先级的提案」，未点名签约方、未给时间表；The Next Web 另称在谈 METR 与 Redwood Research（标「据报道 / 待官方确认」）。对安全/采购侧，合同现在可以要求「safety case 是否允许第三方在训练期读 CoT / 内部署、发现后多久必须公开」，而不是一篇原则稿等于已经有常驻评测员。  
来源：OpenAI https://openai.com/index/priorities-principles-third-party-assessments/ · The Next Web https://thenextweb.com/news/openai-third-party-assessment-priorities-principles

**4. 路透社独家：Meta 为 Muse 电话功能试「human concierge」，内部已回滚**  
同日路透社据内部帖：Meta 在 Muse 公开电话功能后，让外包坐席**悄悄**代打部分美国商家电话（预约、查库存、询价），内部称 human concierge / human agent calls；上周对约一半员工开启，可加入 opt-out 组。昨日简报已写亚马逊用使用条款挡住 Muse 购物，本条是**电话通道增量**。员工反对：敏感信息可能进呼叫中心；一人请 Muse 跟宽带商议价，转写显示坐席在通话中使用种族相关表述。Superintelligence Labs 一位 VP 承认未充分披露是「miss」，并称功能**已回滚**；内部测试写人工代打成功率可到 **95–98%**，高于「较低」的纯 AI 代打。发言人 Daniel Roberts：员工反馈「overwhelmingly positive」，目的是上线前补安全/隐私护栏与披露，且「只在准备好并有适当披露时」对公开放。Sensor Tower：上线约两周下载逾 **250 万**。对 agent 产品，这是「语音 agent 碰到商家挂断 AI 电话」后用人工顶上去的可引用案例；自建外呼栈的人应核对本产品是否向被叫与用户披露「现在是人在打」，以及凭据是否进第三方坐席。

**5. Snorkel AI 完成 3.5 亿美元 Series E，估值 35 亿美元；官方称年化经常性收入约 3.75 亿**  
同日 Snorkel CEO Alex Ratner 官方博文：Insight Partners 与 S32 领投 **3.5 亿美元** Series E，估值 **35 亿美元**；跟投含 Third Point、March、Blumberg 及原股东 Addition、Lightspeed、Greylock、GV、Wells Fargo 等。相对 2025 年 5 月 **1 亿美元 / 13 亿美元**一轮接近三倍。官方：2025 年 9 月转向 data-as-a-service 后增长逾 **18 倍**，宣布当周年化经常性收入跨过 **3.75 亿美元**（路透社转述 CEO 口径为约 **3.5 亿**，以官方博文为准）。业务从卖标注软件转为向前沿实验室交付成品数据集与强化学习环境；路透社：公司预期**今年**盈利。对训练/评测采购，这是把「难任务数据 + RL 环境」写成可交易的数据工厂估值，而不是又一轮算力融资。

**6. 高通 Snapdragon Summit：两款 2nm 旗舰 SoC 主打端侧 agentic AI，Extreme 号称可跑 30B MoE**  
同日夏威夷 Snapdragon Summit，高通发布 **Snapdragon 8 Elite Extreme Gen 6** 与 **Snapdragon 8 Elite Gen 6**，均走台积电 **2nm**，Oryon CPU + 重做的 Adreno GPU + Hexagon NPU。官方定位「agentic AI age」双旗舰：Extreme 给最高端 Android，Gen 6 把同一套 AI / 游戏 / 影像能力放到更宽的高端机。TechCrunch / CNBC：新 sensing hub 可本地跑约 **2 亿**参数小模型（个人听写、说话人分离、按使用建记忆）；Extreme 可在设备上跑约 **300 亿**参数 MoE（只激活部分专家）。首批 OEM 官方名单含 HONOR、iQOO、Motorola、OnePlus、OPPO、REDMI、RedMagic、vivo、Xiaomi。CEO Cristiano Amon：从「以手机为中心」转到「以 agent 为中心」。对端侧/应用栈，这是「把 30B 级 MoE 写进旗舰 BOM」的对账点：下一轮看实际常驻 agent 的内存占用与续航，而不是一场 Summit 等于已经替代云端 token 账单。
