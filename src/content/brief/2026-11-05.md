**1. OpenAI：11 月 4 日写，一次内核扫描归并出 948 个本地提权并送出补丁**  
11 月 4 日 OpenAI 发安全研究博文，写他们用一个尚未点名的网络安全模型，在受控环境里对 Linux 内核做发现、验证和补丁生成。扫描的是 10 月中旬当时的内核主线（10 月中旬，已标明日期，早于主窗口）。博文写，候选发现 2,308 条，动态复现 1,724 条；其中信息泄露的概念验证 291 个。利用阶段做出 1,169 个能让无特权本地用户获得 root 的本地提权利用，变体归并之后是 948 个不同补丁，博文用 948 作为不重复的本地提权数量。同一次运行的 API 额度成本写成 1,213,430 美元，按 948 个计算大约每个 1,279 美元。博文写，人先审阅利用、补丁和严重程度，再向维护者报告；按内核社区的建议，关键漏洞的报告和补丁已经送出数百份，其余经由 Patch the Planet 的合作方逐步送出。扫描和人工分析结束的 10 天里，博文写已有 61 个本地提权在上游被补上，43 个有暂存补丁，299 个正在被公开讨论。同一篇的对照是：6 月 GPT-5.5 Cyber 为验证和报告做过 24 个本地提权利用；7 月下旬 GPT-5.6 Sol 找到并利用 166 个不重复的本地提权，端到端 API 成本 513,690 美元（6 月、7 月下旬，已标明日期）。博文另写，在一份适配过的 kernelCTF 环境里得到 21 个本地提权利用，API 额度大约 32,936 美元。这些都是厂方记录，本简报没有逐条核对哪些补丁已经合入哪个版本。对还在未打最新补丁的系统上跑智能体的人，博文的结论是：对资源充足的一方，一台没跟上补丁的低权限账号，在近期应视为已经等于 root；文中点名用 Firecracker、gVisor 这类沙箱和隔离去限制被利用之后的范围。合同现在可以问对方说的「模型已经扫完内核」，指的是这篇里尚未点名的模型、在 10 月中旬那次运行里归并出的 948 个，还是一份已经写明补丁合入版本的清单。  
来源：OpenAI https://openai.com/index/a-thousand-fewer-paths-to-root/

**2. 月之暗面：11 月 4 日放出 Kimi K3.1 Pro 权重，模型卡写 2.8 万亿参数**  
11 月 4 日 16:00 UTC，Kimi.ai 在 X 发帖，写正在放出 Kimi K3.1 Pro 的模型权重，并链到 Hugging Face 的 moonshotai/Kimi-K3.1-Pro。模型卡写总参数 2.8 万亿，每个 token 激活 1,040 亿，93 层里 1 层是稠密层，注意力层是 69 层 KDA 加 24 层 Gated DSA；896 个专家，每个 token 选 16 个，另有 2 个共享专家；上下文 1,048,576；权重是训练时就量化的 MXFP4，激活是 MXFP8；输入为文本和图像，视觉编码器 MoonViT-V2 为 4.01 亿参数。卡上写，相对 Kimi K3，全注意力的 Gated MLA 换成了 Gated DSA。评测表注明，未另加说明时 K3.1 Pro 用 reasoning effort max、temperature 1.0、top_p 0.95。Terminal-Bench 4.0 一栏是 65.7，Claude Opus 5.5 是 66.4，GPT-6 Astra 是 58.2；脚注写 K3.1 Pro 用 Claude Code 评，其余分数取自模型博客或官方榜的最高值。SWE Marathon v1.1 一栏是 51.7，Opus 5.5 是 46.3；脚注写 K3.1 Pro 同样用 Claude Code，其他分数来自官方榜。许可证是 Kimi K3.1 Pro License，不是 Apache，也不是 MIT。文本写，若把推理或微调以 API 等方式做成 Model as a Service，且许可方及其关联方在任意连续 12 个月合计收入超过 2,000 万美元，商业使用前必须另与 Moonshot AI 签约；月活超过 1 亿、或月收入超过 2,000 万美元的商业产品，界面必须显著标出 “Kimi K3.1-Pro”。内部使用，以及通过 Moonshot 官方产品或认证推理伙伴使用，不适用这两条。对要把「已经开源，而且 Terminal-Bench 超过 Opus 5.5」写进选型的人，现在能核对的是这个仓库、一张 65.7 对 66.4 的表，以及一份收入过线就要另签的许可证。合同现在可以问对方说的 Kimi K3.1 Pro，指的是这个仓库里的权重，还是许可证写明不触发上述两条的官方 API。  
来源：Hugging Face https://huggingface.co/moonshotai/Kimi-K3.1-Pro · X https://x.com/Kimi_Moonshot/status/2118010528123773297 · Hugging Face https://huggingface.co/moonshotai/Kimi-K3.1-Pro/blob/main/LICENSE

**3. 腾讯：11 月 4 日放出 Hy4 的 API，权重和系统卡仍写计划开源**  
11 月 4 日腾讯 Hy 研究页发布 Hy4。页面写，这一版第一次加上视觉，并第一次支持计算机使用，范围包括命令行和图形界面；并写针对 Blender、CAD 以及跨应用的长流程做过训练。同一页写，API 已在腾讯云和 OpenRouter 提供，产品侧包括 CodeBuddy、WorkBuddy、元宝和 ima，价格与 Hy4 preview 相同。表上每百万 token 是缓存输入 0.042 美元、输入 0.834 美元、输出 2.501 美元。页面写计划开源 Hy4 的权重，并已与 vLLM（Inferact）和 SGLang 社区合作；放出权重时会同时发系统卡。因此页面里「第一次进入最强开源模型之列」是厂方说法，本简报打开该页时，Hy4 权重还不在这篇所写的已发布之列。金融一段写，213 名从业者里 153 名来自机构，超过 70% 有五年以上经验；579 项任务上 Hy4 是 3.04，DeepSeek-V4.1-Flash-1017 是 2.97，Kimi K3.1 Pro 是 2.68，GLM-5.3 是 2.68，页面把它写成开源权重模型里的第一。相对 preview，内部幻觉率从 15.76% 降到 5.45%，臆测错误从 23.1% 降到 5.6%；GameDev 高 19.1%，GameLogic 高 9.8%。生物安全一段写，Hy-BioExperimentBench 是 30.4/100，内部专家认为把知识写成可执行实验方案的能力仍然有限，没有发现 Hy4 实质降低造成生物伤害的门槛。这些分数都是厂方记录。对要把「Hy4 已经能下载」写进部署的人，现在能核对的是这份 API 和价格，以及页面写明还要等的权重和系统卡。合同现在可以问对方说的 Hy4，指的是这篇里已经挂上的接口，还是页面写明尚未放出的权重。  
来源：Tencent Hy https://hy.tencent.ai/research/hy4

**4. OpenAI：宣布收购 Pierre，交割前两家仍独立，通稿未写对价**  
11 月 4 日 OpenAI 宣布将收购 Pierre Computer Company, Inc.，也就是 Code Storage 和一组开源开发工具的公司。博文写，在 Codex 应用里浏览文件或查看改动，用的已经是 Pierre 的 Trees 和 Diffs。Diffs 的 Edit 模式可以在差异处改一行；Highlights 随人的输入或智能体的输出更新语法高亮。Code Storage 让应用用 Git 存代码并跟踪历史。博文写，开源项目交割后继续开源，OpenAI 会继续贡献；交割之后客户仍可使用 Code Storage，同时他们把功能做进 Codex。脚注写，交割取决于惯常条件，包括监管批准；交割前两家仍是各自独立的公司。通稿没有写对价、换股比例或交割日期。近三日已写 Pando；这篇把 Pando 称作本周早些时候公布的内部源码后端，本条是这笔尚未交割的收购。对要把「Codex 已经换成 Pierre 的代码托管」写进迁移计划的人，现在能核对的是一份还没交割、而且没有写出对价的宣布。合同现在可以问对方说的 Pierre，指的是交割前仍然独立、Codex 里已经在用的 Trees 和 Diffs，还是通稿写明要等交割之后才放进 Codex 的 Code Storage。  
来源：OpenAI https://openai.com/index/openai-to-acquire-pierre/

**5. AMD：第三季数据中心收入写成 85 亿美元，第四季收入指引约 170 亿美元**  
11 月 3 日 AMD 在提交给美国证券交易委员会的业绩通稿里写，第三季收入 134 亿美元，毛利率 54%，经营利润 28 亿美元，净利润 24 亿美元，稀释每股收益 1.46 美元。非 GAAP 毛利率 56%，经营利润 39 亿美元，净利润 35 亿美元，稀释每股收益 2.09 美元。表上的百万美元数更细：收入 13,377，GAAP 经营利润 2,832、净利润 2,428，非 GAAP 经营利润 3,923、净利润 3,471；非 GAAP 稀释每股收益同比增 74%，GAAP 稀释每股收益同比增 95%。数据中心分部收入写成创纪录的 85 亿美元，同比增长 97%，通稿归因于 EPYC 的需求和 Instinct MI450 系列的推出。Lisa Su 写，收入超过此前指引的高端，并预期第四季随着 Helios 和 Venice 放量，增长还会加快；这是公司预期。第四季指引是收入约 170 亿美元，上下 3%；区间中点大约同比增 66%、环比增 27%；非 GAAP 毛利率预期约 55%。通稿的近期要点另写，Anthropic、Meta、微软、OpenAI 和 Oracle Cloud Infrastructure 正在第一批 Helios 机架上跑模型和负载，方案用 MI450 和第六代 EPYC；这是通稿自己的写法。对要按「AMD 的 AI 芯片已经按 170 亿美元一个季度在卖」锁产能的人，通稿能核对的是已经发生的第三季 85 亿美元数据中心收入，以及一份仍是指引的第四季公司收入。合同现在可以问对方说的 170 亿美元，指的是这份第四季公司收入指引的中点，还是已经计入报表的第三季数据中心收入 85 亿美元。  
来源：SEC https://ir.amd.com/financial-information/sec-filings/content/0000002488-26-000188/q32026991.htm
