**3. DeepMind：11 月 11 日放出 AlphaGenome 2，写在 TenK10K 上识别出的因果变异是 30% 对 16%，非商业研究当天可经 API 使用**  
11 月 11 日 Adam Gayoso、Natasha Latysheva、Pushmeet Kohli 与 Žiga Avsec 发博文，介绍 AlphaGenome 2。博文写，它预测 DNA 序列及其变异如何影响特定的人类细胞类型。开篇写，相对此前的最好模型，它识别出将近两倍会改变细胞里基因表达的变异；训练用了超过 1 亿份单细胞图谱、覆盖 68 种组织。后文把训练数据写成超过 1.07 亿份来自人和小鼠的单细胞图谱。非商业研究当天可通过 AlphaGenome API 使用，商业研究是私人预览。文末写，AlphaGenome 与 AlphaGenome 2 只供研究，没有为临床或诊断做过验证或批准。模型被写成条件式：一次预测一种条件（组织、细胞类型或状态），输入仍是 100 万个字母的 DNA；科学家也可以把自己的单细胞实验经细胞编码器收成条件。博文写，因此可以做跨模态填补，例如只给单细胞基因活性，再预测尚未测量的染色质可及性。预测读出包括原来就有的基因表达、组蛋白修饰和染色质可及性，并加上 DNA 甲基化。TenK10K 被写成 28 种原代免疫细胞的单细胞图谱。博文写，相对在单细胞数据上微调过的原版 AlphaGenome 以及其他专用工具，AlphaGenome 2 可靠识别出的因果变异是 30% 对 16%，方向性基因效应是 43% 对 23%。炎症性肠病一段写的是计算上复现一篇已发表的研究：远端调控开关里的一个变异通过在肠道巨噬细胞里过度激活 ETS2 起作用；AlphaGenome 2 在多种肠道免疫细胞上的预测把这个因果变异标出来，并写成它选择性提高肠道巨噬细胞里的 ETS2，其他细胞类型和基因大体不受影响。这是博文对一次计算复现的记录，不是新的患者实验。另写，上传几十个细胞的单细胞 RNA 测序就能适配没见过的状态，不必重新训练。例子是一份未见过的 COVID-19 mRNA 疫苗研究数据：模型区分疫苗激活的免疫 T 细胞和静息细胞，并写一个与重症 COVID-19 相关的变异在激活状态下对基因活性的干扰更强。预计算覆盖数百种人类细胞与组织条件，用来把全基因组关联研究里的变异接到单细胞图谱；增强子—基因连接被写成延伸到原代人类细胞类型，例子是脑星形胶质细胞。剑桥大学干细胞医学教授、Human Cell Atlas 联合创始人 Sarah Teichmann，以及 Genomics Limited 首席执行官 Peter Donnelly 的引语在同一页。博文写，AlphaGenome 2 的技能随后会进 Google Antigravity，没有给日期；征集使用案例的表写到 11 月 30 日。论文 PDF 链在这篇博文里，本简报没有重跑模型，也没有打开 PDF 核对补充表。对要把「AlphaGenome 2 已经能做临床诊断，而且因果变异召回是 30%」写进检验流程的人，现在能核对的是文末的研究用途限定，以及 30% 与 43% 来自 TenK10K 上、对照微调原版和其他专用工具的厂方比较。合同现在可以问对方说的 AlphaGenome 2 已可用，指的是这篇里非商业研究的 API，还是一份已经开放的商业接口和已经做完的临床验证。

**5. Google：11 月 11 日放出 Gemini Decisions API 与模型 gemini-decision-1，输入价写成每百万 token 0.10 美元，输出不计费**  
11 月 11 日 Min Choi 与 Felix Yu 发博文，头衔分别是 Google DeepMind 产品经理和首席科学家。博文介绍 Gemini Decisions API，底层模型是 Gemini Decision 1，模型名写成 gemini-decision-1，经 Google AI Studio 里的 Gemini API 提供。用途写成有界选择：工具选择、策略检查、模型路由和上下文评分。一次请求可以带一段多模态输入，包括文本、图像、音频、视频和 PDF，最多 256K token，再加最多 1,000 个彼此独立的问题。博文写，模型不是逐 token 生成答案，而是在一次前向传播里给候选选项打分，返回概率和 0 到 1 的置信度。延迟写成：在多模态输入、上下文最多 16K token、每个请求大约 1 到 100 个问题时，模型计算的中位延迟是 50 到 100 毫秒，端到端是 150 到 250 毫秒，并且从 1 个问题到 100 个问题几乎持平。本简报不把这组毫秒数写成 256K token 上下文上的延迟，因为博文把 150 到 250 毫秒跟最多 16K token 的那段放在一起。价格写成每百万输入 token 0.10 美元，输出 token 计费为 0。共享的 input 每个请求只计一次，每个问题再加它自己的说明和标准 token。博文写，在一套共用基准上，相对使用 Interactions API 的 Gemini 3.5 Flash-Lite，Decision 1 加 Decisions API 接近便宜 5 倍；并写 Decision 1 在这套覆盖智能体路由、推理、排序和多模态理解的基准上领先，校准误差最低。正文没有列出各家分数，本简报没有重跑这套基准。三种问题写成：noul 是是/否，可附真与假的说明；choice 是 2 到 255 个选项，返回胜出项和每个候选的归一化概率；score 是从 0 起的有序量表，返回连续加权分和每一级的概率。内部用法是这篇博文的记录：Gemini Notebook 用它做实时路由，博文写日常查询的延迟最多低 40%；Stitch 的 rapid canvas 用它在数秒内生成可操作的线框；Google Labs 的 CC 用它从超过 200 个表情里挑选；Google Search 用它在 MCP 工具上检测对抗行为和内容。生态写成正在接到 OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI、Pipecat、LiveKit 和 OpenCode，以及 google-genai SDK。Google Cloud 上的 Gemini 写成即将支持，页上是一份表，没有日期。AI Studio 里有不计费的原型档。对要把「0.10 美元已经覆盖 256K 上下文上 150 毫秒的决策，而且 Cloud 已经一般可用」写进路由预算的人，现在能核对的是 0.10 美元与输出不计费，以及 150 到 250 毫秒写在最多 16K token 的那一段。合同现在可以问对方说的 Decisions API 已可用，指的是这篇 11 月 11 日博文里 AI Studio 的端点，还是一份已经写明区域、配额和 Cloud 一般可用日期的说明。
