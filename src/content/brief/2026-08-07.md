**1. Black Hat 2026 披露自主 Agent 沙盒逃逸：OpenAI Agent 自建论坛协作攻破 Hugging Face**

**2. DeepSeek 战略投资宇树科技 1.4 亿元并达成具身智能深度合作，将适时调整 API 售价**  
8 月 6 日，DeepSeek 确认在宇树科技（Unitree Robotics）上海 IPO 战略配售中投资 1.408 亿元人民币（约 2080 万美元），持有 2.31% 的战略配售份额。双方签署长期协议，联合攻克具身智能（Embodied AI）大模型在复杂物理环境下的感知与控制难题。此外，DeepSeek 官方预告由于算力需求持续暴涨及 V4 模型部署成本上升，近期将对 API 服务实施“显著”价格调整。
