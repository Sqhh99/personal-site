**1. Anthropic 威胁情报报告：点名七家中国实验室蒸馏 Claude，并披露俄系间谍与常规武器误用**  
9 月 10 日（周四），Anthropic 发布迄今最详细的威胁情报报告 *Detecting and countering misuse of AI: September 2026*，覆盖 **2025 年 12 月至 2026 年 8 月**、七个危害领域：网络行动、影响力、监控、诈骗、生物误用、常规武器开发、非法蒸馏。厂方口径：人类多半是「定目标、审外泄」的监督者，真正执行侦察、利用与外泄的是多 agent 框架；「AI 已经把过去区分国家队与个人的劳动力与工具鸿沟压扁」。涉案模型是 Claude Haiku / Sonnet / Opus；除一起蒸馏外，未见 Fable / Mythos 被用于恶意活动。蒸馏侧：厂方称期间打掉七家中国实验室相关攻击，点名阿里、Moonshot、DeepSeek、小米、智谱等。路透社：与阿里相关的操作被写成迄今最大的「非法蒸馏」——**2026 年 5–7 月**逾 **1.51 亿**次交互、峰值近 **300 万**次/日、来自逾 **3500** 个被标为欺诈的账号，目标是抽出 Opus 推理喂给 Qwen 3.5 / 3.6 / 3.7；阿里未立即回应。Moonshot 与 DeepSeek 则被指不走批量查询，而是把真实用户对话（含敏感信息）中转到 Claude、再拿回复当训练数据——这是 Anthropic 单方指控。网络侧：GTG-20006 的归因「与公开报道中的 Midnight Blizzard 一致」，对乌克兰、欧洲政府、外交与防务目标做钓鱼、酒店 Wi-Fi DNS 劫持与 WhatsApp 接管，侦察与实操覆盖逾 **20** 个组织；恶意软件一旦被检出，agent 会自动改写、重编译直到绕过签名。报告另写：中国、俄罗斯、也门有操作者用 Claude 写常规武器（枪械、导弹、武装无人机、炸弹）相关软件或采购情报。对运行侧，这是把 9 月 8 日美方蒸馏通告从「政府点名」写成平台侧可对账的 TTPs：自建网关若对高风险地区或聚合器开放 Opus 级推理，检测默认要按百万级伪造账号、跨会话中转与「把 CoT 强制写出来」来设计，而不是只拦单个 IP。

**2. DeepSeek 正式发布 V4.1 Flash：552B MoE、非对称 8B/16B 激活，KV cache 压到上一代约 1/4**  
同日，DeepSeek 官宣 **DeepSeek-V4.1-Flash**：自称新架构家族里最小的一档，原生多模态。骨干 **552B** 参数 MoE，新 Causal Encoder–Decoder：prefill 每 token 激活 **8B**、decode 激活 **16B**；厂方称 KV cache 相对上一代 V4-Flash 只需约 **1/4** 的 HBM、约 **1/8** 的 SSD。Hugging Face 技术报告：全局 KV cache 约 **890 字节/token**；从零训 **45T** token 多模态语料，上下文到 **1M**；权重 MIT 开源。厂方 max-effort 数字（非第三方复现）：Terminal-Bench 2.1 **90.6**、DeepSWE v1.1 **74.2**、CyberGym **88.1**、GPQA Diamond **90.9**、Codeforces 评分 **3471**，并自称在性能、费用、速度与总用时上已超过自家 V4 Pro。API 模型名改为 `deepseek-flash`；旧名 `deepseek-v4-flash` / `deepseek-v4-flash-vision-exp` 暂时路由到新模型。**北京时间 9 月 14 日 12:00** 起、直到未来的 V4.1 Pro 上线前，所有 `deepseek-v4-pro` 请求将路由到 V4.1 Flash 并按 Flash 单价计费。峰谷定价继续：闲时为高峰价一半，新价于 **9 月 10 日 04:00 UTC** 生效。TechNode 转述 IT 之家：闲时 cache-hit 输入 **0.02** 元/百万 token、cache-miss **1** 元、输出 **4** 元，高峰翻倍。对工程侧，这是把「agent 变贵是因为反复 prefill + 百万级 KV」写成可部署的架构答案：自建长程 agent 的人，下一轮选型应先对 HBM 占用与 cache-hit 账单，而不是只盯激活参数；同时注意——同一天 Anthropic 把 DeepSeek 写成蒸馏对象，开源权重与 API 降价是产品事实，蒸馏指控是单方指控。

**3. OpenAI Agents API 公测：把 Codex 的托管 harness 做成一次调用的云端 agent**  
同日 OpenAI 官方：Agents API 进入 public beta，把驱动 Codex 与 ChatGPT for Work 的同一套 harness——会话、编排、上下文压缩、恢复——交给开发者；一次调用指定任务、模型、工具与运行环境。厂方托管 harness，计算环境三选一：OpenAI 托管沙箱、自有基础设施、或合作方沙箱（点名 Blaxel、Cloudflare、Daytona、DigitalOcean、E2B、Modal、Oracle、Runloop、Vercel）。能力面：会话接近上限时自动 compaction；tool search 按需加载工具定义；programmatic tool calling 可并行、链式调用；multi-agent 可把任务拆给并发子 agent。底层是开源 Codex harness（GitHub `openai/codex`），公司运维、开发者可读。不计额外 API 费，只付 token 与工具。客户口径（公司通稿，非独立审计）：SafetyKit 单案成本降 **60%**；Hypha 失败响应降 **86%**；Ciridae 评估分从 **0.71** 到 **0.85**、子 agent 延迟降约 **4** 倍。对开发侧，这是把「自己写 agent 循环」从默认路径写成可选：自建长程 agent 的人，现在要决定的是沙箱落在谁的 VPC、compaction 与子 agent 编排要不要外包给 Codex harness，而不是再从零实现会话恢复。  
来源：OpenAI https://openai.com/index/introducing-the-agents-api/ · 开发者文档 https://developers.openai.com/api/docs/guides/agents-api/overview · Investing.com（转述）https://www.investing.com/news/stock-market-news/openai-launches-agents-api-in-public-beta-for-developers-93CH-4896757

**4. Positron 完成 8.75 亿美元 C 轮，投后 50 亿美元；下一代推理硅片走 LPDDR、躲开 HBM**  
同日 Positron AI 官方通稿并经路透社、WSJ 核实：两档合计最多 **8.75** 亿美元——**3.75** 亿 Series C（投前 **35** 亿）+ 最多 **5** 亿 Series C-1，投后 **50** 亿美元。七个月前 2 月一轮是 **2.3** 亿、估值约 **10.6** 亿（PitchBook）。联合领投：NEA、Atreides、Valor、Andra、Dylan Patel 的 SemiAnalysis Capital、网景联合创始人 Jim Clark；跟投含卡塔尔投资局、Cisco Investments、Naver Ventures。用途：Asimov 流片（TSMC **N3P**，2026 年底 tapeout、**2027 年下半年**量产）、**2 MW+** 工程机房与仿真平台、以及 Titan 量产（含 LPDDR5X 锁货）。Titan 单节点 **4–8** 颗 Asimov，厂方目标是单节点服务超过 **16 万亿**参数、上下文超过 **1000 万** token。产品叙事明确：下一代不绑 HBM / CoWoS，用商品级 LPDDR5X；第一代 Atlas 已在 Oracle Cloud Infrastructure 部署逾 **50** 机柜，客户点名 Parasail、Jump Trading、i3d.net。对采购侧，这是把「推理硅片」从 NVIDIA + 云厂自研写成第三条腿的又一张支票：锁机柜的人，明年 BOM 里可能多一栏「内存优先、空气冷却也能上」的推理架，而不是只盯 Rubin 的 HBM4 交期；量产仍在 2027 下半年，现在买到的是 Atlas 而不是 Asimov。

**5. 路透社独家：华为昇腾、寒武纪等上调 AI 加速卡报价，HBM 灰市溢价传导到整卡**  
同日路透社发自三名知情人士（未具名，标「据报道」）：华为把昇腾 **950DT** 加速卡指示价抬到逾 **25 万元**人民币（约 **3.73 万美元**），相对两个月前报价涨 **20–50%**（视合同条款）；该卡厂方公开口径是 2026 年四季度供货。寒武纪下一代（暂称 **690**）指示价相对两个月前涨 **20–30%**，未给绝对数字；沐曦、天数智芯有类似上调。更早的卡也在涨：950PR 从年初约 **6 万**到逾 **8 万**（约 +**30%**），910C 从约 **9 万**到逾 **11 万**。结构性原因：2024 年 12 月美国收紧先进 HBM 对华出口后，中国厂商更多走灰市，知情人士称这类 HBM 往往是境外买家的数倍；内存占加速卡成本大头，溢价直接进整卡。华为、寒武纪、沐曦、天数智芯均未回应置评。对采购侧，这是把 9 月 7 日券商「内存库存不足 10 天」从韩国货架写成中国替代链的报价单：锁国产加速卡的人，明年真正的变量可能是 HBM 灰市价而不是 GPU 流片本身；能躲开 HBM 的架构（见上条 Positron 的 LPDDR 路线）会先出现在 BOM 讨论里。
