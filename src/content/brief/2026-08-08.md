**要闻（3–6 条）**

**1. Google DeepMind 管理层重大重组：Demis Hassabis 转任 Alphabet 首席科学家兼 DeepMind 主席，Koray Kavukcuoglu 接掌日常运营**  
Google 正式宣布 DeepMind 人事调整：联合创始人 Demis Hassabis 卸任 CEO，出任 Alphabet 首位首席科学家（接替离职创立新架构公司 Discovery Loop 的前首席科学家 Jeff Dean）兼 DeepMind 主席，并继续领导旗下 AI 制药公司 Isomorphic Labs；原 CTO Koray Kavukcuoglu 升任高级副总裁（SVP）并兼任首席 AI 架构师，直接向 Alphabet CEO Sundar Pichai 汇报，全面执掌 Gemini 研发、前沿研究与产品团队。此举标志着 Google 研发体系进一步深化工程落地与基础科学探索的双轨分离。  
来源：Google Blog https://blog.google/technology/ai/google-deepmind-leadership-update-2026 · The Guardian https://www.theguardian.com/technology/2026/aug/06/demis-hassabis-chief-scientist-alphabet-google-deepmind

**2. NVIDIA 联合 Google/Intel/Meta 成立 XIO-SIG 并开源 cuFile API，发布 SCADA 突破 GPU 原生存储控制瓶颈**  
在 Future of Memory and Storage (FMS 2026) 大会上，NVIDIA 宣布正式开源 GPUDirect Storage (GDS) 核心组件 cuFile API 及垂直软件栈，并联合 Google、Intel、Meta 等作为首发维护者成立 Accelerated IO Special Interest Group (XIO-SIG)。同时推出的 SCADA 框架将原本依赖 CPU 的存储 I/O 控制路径完全下放给 GPU 自身，支持 GPU 自主发起并闭环数十万并发存储请求，将 I/O 延迟压低至微秒级，为万卡集群大模型推理上下文换入换出与 Agent 知识库吞吐消除总线制约。  
来源：NVIDIA Developer https://developer.nvidia.com/gpudirect-storage · StorageReview https://www.storagereview.com/news/nvidia-open-sources-cufile-apis-announces-storage-next-and-scada-at-fms-2026

**3. Meta 发布终端自主编码 Agent「Muse Code」：搭载 Muse Spark 1.2 模型，支持多子智能体协作与工作区隔离**  
Meta 正式推出面向开发者的终端原生自主编码工具 Muse Code（Beta），底层由最新 Muse Spark 1.2 驱动。该工具采用常驻子智能体（Persistent Subagents）调度架构，支持在大型代码库中自主制定重构计划、多文件编码与测试验证；引入断点安全本地事件日志与 Git Worktree 隔离机制，支持多分支并发任务与随时中断恢复。Meta 同时推出贡献者定价阶梯，用户允许贡献训练数据可享受近 90% 的 API Token 成本减免。  
来源：Meta AI https://dev.meta.ai/code · TechCrunch https://techcrunch.com/2026/08/05/meta-launches-muse-code-terminal-ai-agent/

**4. 阿里巴巴发布 2.4 万亿参数旗舰模型 Qwen3.8-Max 并宣布 8 月中旬开源权重，公测企业级「千问办公」**  
阿里巴巴正式推出旗舰级混合专家（MoE）大模型 Qwen3.8-Max，模型总参数量达 2.4 万亿（2.4T），单次推理激活约 950 亿参数，在长逻辑推理、科研推演与全模态长周期任务上显著提升。阿里宣布将于 8 月中旬向全球开发者开源 Qwen3.8-Max 权重及轻量化 Qwen3.8-27B，这是业界首次开源万亿级 MoE 顶尖基座；同步开启企业级 Agent 协作平台“千问办公（QwenWork）”公测。  
来源：Alibaba Cloud https://www.alibabacloud.com/blog/qwen3-8-max-announcement · Qwen LM https://qwenlm.github.io/blog/qwen3.8-max/

**5. DARPA 完成现役 F-16 战机 VENOM 自主飞行实战测试：AI 飞控套件即插即用并支持人机无缝交接**  
美国国防高级研究计划局（DARPA）与美空军在埃格林空军基地完成 VENOM（毒蛇实验与下一代作战模型）自主飞行实测。试验通过在现役标准 F-16 机身上加装无需修改核心飞控硬件的自主套件（VAK），成功由 AI 智能体自主接管飞行与战术机动；驾驶舱保留物理切换拨片以维持人在回路监控（Human-on-the-loop），验证了前沿强化学习算法在超高动态物理工控系统中的即插即用与安全接管范式。  
来源：US Air Force https://www.af.mil/News/Article-Display/Article/3715800/venom-f-16-ai-autonomy-test-flight-eglin/ · DARPA https://www.darpa.mil/news-events/2026-08-06-venom-autonomy-flight
