**1. OpenAI 公开确认与 Anthropic、Google DeepMind 协调安全；Lehane 称不需要反托拉斯豁免，并支持 FRONTIER Act 的独立核验条款**  
9 月 15 日（周二），OpenAI 全球政策负责人 Chris Lehane 在华盛顿简报会上说，公司与 Anthropic、Google DeepMind 的安全磋商「已经进行了数周」。原句：「It's better to try to work together to prioritize safety。」他明确表示，三家实验室**不需要**反托拉斯豁免才能协调安全事项，并拿航空业安全协作作类比。Bloomberg 首发、路透社跟进；路透社另写 OpenAI、Alphabet、Anthropic 当时未立即回应其求证。这是对 9 月 13 日《信息报》「三家自 7 月起开工作组」的**厂方公开增量**：从知情人士口径写成政策官可引用的表态，不是董事会停训决议，也不是 Astra / Fable 下架。同日 Lehane 对 Politico / CBS：OpenAI 支持众议员 Jay Obernolte（共和党，加州）与 Lori Trahan（民主党，麻州）提出的 FRONTIER Act 中「Independent Verification Organizations」（IVO）条款——要求达到营收与算力门槛的前沿实验室允许第三方评估员进入公司核验模型安全；CBS 写明这是 OpenAI **首次**公开支持联邦层面的第三方强制核验，但发言人强调**并未背书整部法案**。路透社：公司另背书 Web of Biological Data Act、AI-Ready Bio-Data Standards Act 与 SCALE Biology Act 三份生物数据/生物威胁相关两党法案。对运行侧，合同里现在可以点名「IVO 一旦立法、嵌入评估员从自愿变成法定义务」；同时也要预留「Lehane 说不需要豁免、但协调放缓若被读成限制产量，Sherman Act 风险仍在」的分叉。

**2. 黄仁勋在 Dreamforce / CNBC 对案：反托拉斯豁免「完全没必要」；安全是工程问题，不是新法问题**  
同日，NVIDIA CEO 黄仁勋在旧金山 Dreamforce 与 Anthropic CEO Dario Amodei 同台后，对 CNBC *Mad Money* 说：「The fact that we need new laws, new antitrust laws, or new regulations, so that these companies could do their fundamental engineering and do it properly before they release products, that is just completely unnecessary。」他写安全是真问题，但路径是「Safety is an engineering problem. Testing is an engineering problem」——产品没测完就先别发，而不是向政府要豁免好让竞争对手商量放慢。另说「We're not going to die in 2030」。Guardian：Amodei 在 Dreamforce 重申三步框架（嵌入评估员、民主国家协调、全球协调）；黄仁勋稍后回「Run as fast as you can」。这是对 9 月 14 日 All-In Summit 特朗普免提电话「You're right. We're not going to let that happen, sir」的**周二产品化增量**：芯片商把「放缓」从总统社媒写成可引用的工程口径。NVIDIA 同时是 Anthropic 与 OpenAI 的重要客户，也有自研开源权重 Nemotron。对产业侧，锁 GPU 配额的人不要把 CEO 联名读成 capex 停表——黄仁勋把「自愿放缓」写成单家工程决策，把「行业协调上限」写成不必要的新法。

**4. Google 发布 Gemini 3.8 Live 与 3.8 Live Extended Thinking：语音 Agent 可边说边调工具**  
同日，Google 官方博客发布两款原生语音到语音模型。Gemini 3.8 Live 面向规模与成本，带视觉 grounding、97 种语言中途切换、后台异步函数调用；3.8 Live Extended Thinking 面向复杂多步任务，厂方称可边推理边口述进度。基准（厂方数字）：Extended Thinking 在 Artificial Analysis Speech-to-Speech Quality Index 总分 **82.6** 暂列第一，τ-Voice **68.6%**、Sierra τ-Voice-banking **35.1%**、Big Bench Audio **97.7%**；Live 在 Speech Agent Arena 排第二。开发者侧：Gemini API / Google AI Studio 即日起可用，Live API 报价音频输入 **$0.005/分钟**、输出 **$0.018/分钟**（脚注按输入 $3 / 输出 $12 每百万 token 估算）。企业侧：Gemini Enterprise 私有预览；面向所有人的 Search Live 先上 3.8 Live，Gemini Live 与 Workspace（Docs / Gmail / Keep）上 Extended Thinking。音频输出带 SynthID 水印。模型卡：基于 Gemini 3 Pro，上下文 **128K**、输出 **64K**，输入音频/图像/视频/文本。对开发侧，这是把 GPT-Live-1（9 月 10 日已覆盖）之后的语音 Agent 竞争写成可对账的价目表与工具调用语义：自建实时语音栈的人，下一轮对账的是异步 function calling 能不能在对话不中断的情况下跑完多步工作流，而不是一段演示音频等于生产 SLA。

**5. Salesforce 与 NVIDIA 发布 Koa：在 Nemotron 3 Super 上后训练的 CRM 推理模型，权重不出信任边界**  
同日 Dreamforce，Salesforce 与 NVIDIA 宣布 Koa——Salesforce 第一款面向 Agentforce 的 CRM 推理模型。做法：在 NVIDIA 开源权重 **Nemotron 3 Super** 上，用近 **27** 年 CRM 部署知识建模的**合成数据**做后训练（厂方强调「Not a single byte of customer data was used」）；覆盖 14 个以上行业的 persona、工具调用序列。训练栈写明 SFT + GRPO，用 NVIDIA NeMo RL / NeMo Gym / NeMo AutoModel。Salesforce 自称在内部 CRM Benchmark（改商机、分案、约跟进）上达到或超过通用前沿模型、错误率约 **1/3**。关键产品决策：Salesforce **控制权重**，后训练与推理都在自家信任边界内，作为 Agentforce 里可选的托管模型，而不是把 CRM 工作流转给 Claude / ChatGPT。已在内部 Slack 员工 agent 使用；试点客户包括 Formula 1、UChicago Medicine、Baxter Credit Union、1-800Accountant、Engine、Xero。时间表：精选客户现可试点，美国区域 **2026 年冬季** GA；Missionforce Operations 现已 GA，后训练 NVIDIA 模型 **10 月**向精选客户开放（私有云 / 隔离网）。TechCrunch 把这写成企业需求与前沿实验室的分叉：要数据驻留、工具调用准、token 更省，而不是下一档通用能力。对采购侧，锁 CRM / 政务 agent 的人，下一轮对账的是「开源基座 + 合成后训练 + 权重自持」能不能替代闭源 API，而不是一篇发布会等于已经切完流量。
