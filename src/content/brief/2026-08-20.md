**要闻（3–6 条）**

**1. DeepSeek 开源智能体运行框架 Harness**  
DeepSeek 正式发布并开源了智能体运行框架 DeepSeek Harness (v0.1)。该框架采用“一切皆插件”的设计，允许开发者通过组合插件快速接入模型、工具与环境。它旨在为开发者构建复杂 Agent 系统提供底层的执行底座，进一步完善了其大模型生态体系。  
来源：GitHub https://github.com/deepseek-ai/deepseek-harness

**2. OpenAI 推出“零数据保留”与私有安全处理机制**  
OpenAI 面向企业级 API 客户推出了“零数据保留（ZDR）”选项及“私有安全处理”预览版。此机制允许系统在不让 OpenAI 内部员工接触客户底层内容的前提下，依然能够通过跨交互模式识别潜在的违规与滥用，解决了严格合规（如 HIPAA 等）场景下数据隐私与模型安全防护的冲突。  
来源：OpenAI Platform https://platform.openai.com/docs/guides/data-controls

**3. FBI、NSA 联合警示：AI 驱动的工业网络攻击加剧**  
FBI、NSA 与 CISA 联合发布安全警报，指出近期出现利用 AI 生成恶意脚本以攻击西门子等工业控制设备的威胁活动。在针对 Hugging Face 平台及相关漏洞利用的过程中，攻击者通过 AI 降低了攻击门槛。这促使 Palo Alto Networks 等安全公司推出专门针对前沿 AI 的关键防御计划。  
来源：Cybersecurity Dive https://www.cybersecuritydive.com/news/ai-fueled-cyberattacks-fbi/724581/
