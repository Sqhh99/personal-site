**要闻（5 条）**

**1. 国土安全部：文职机构须移除 DeepSeek，并排除其产品采购，含用其实现开发的第三方**  
10 月 19 日公开、预定 10 月 20 日刊登《联邦公报》的通知（FR Doc. 2026-21447，案卷 DHS-2026-0628）写，国土安全部长已下令两件事：把杭州深度求索人工智能有限公司及其按 48 CFR 2.101 定义的关联实体所开发的信息技术产品和服务，排除出联邦文职机构采购；从文职机构的信息技术里移除全部 DeepSeek 及关联方产品，以及使用 DeepSeek 实现开发的第三方产品和服务。依据是《2018 年联邦采购供应链安全法》。BBC 同日报道，命令在周一公开，但禁令从 7 月底已经生效（标明日期）；BBC 写这份通知没有说明具体安全关切，并写国防部不在此列，文职部门举例包括财政部、国务院和司法部。近三日已写 V4.1-Flash-1017 的权重和 API；本条是移除令公开文本的增量。对向美国文职机构供货的团队，范围写到「用 DeepSeek 实现开发的第三方产品」，不只是官网聊天机器人；合同现在可以问交付物算不算这条里的 implementation，以及 7 月底生效是指已经部署的实例，还是只约束此后的新采购。  
来源：Federal Register https://public-inspection.federalregister.gov/2026-21447.pdf · BBC https://www.bbc.co.uk/news/articles/cjkgeq0k1wevo

**2. Meta：俄亥俄 Prometheus 一期已训练 Muse，预训练 goodput 超过 85%**  
10 月 19 日 Meta 工程博客写，俄亥俄州 New Albany 的 Prometheus 超算一期已经完成，并用来训练 Muse 基础模型，其中包括 Muse Wonder。厂方写当前是数十万块 GPU，跨多栋楼用光纤连成一台机器，满配目标大约 **100 万**块 GPU。Muse Wonder 的预训练 goodput 超过 **85%**，强化学习超过 **90%**；这些训练运行的墙钟平均故障间隔约 **4.7 万** GPU 小时，其后的固件修复把这一数字提到 **5.4 万**以上。在役平台有两代：Catalina 用 GB200 NVL72 的 Ariel 双机架，72 块 Blackwell、每卡 **192GB** HBM3e，双机架功耗约 **120 kW**；Clemente 用 GB300 NVL72，每卡 HBM 提到 **288GB**，单机架约 **135 kW**，厂方写峰值 FP4 超过 **1 exaFLOP**，相对 GB200 NVL72 的性能提高 **5%–10%**。厂方并写基于 Vera Rubin NVL72 的第三代即将到位。近三日已写 Muse Spark Open 与 Muse Wonder 的模型发布；本条是训练集群规模和 goodput 的增量。对估训练账单的人，100 万是满配目标，不是今天已经装完的数量；合同现在可以问买到的容量在 GB200 还是 GB300，以及 85% 的 goodput 含不含重计算。  
来源：Engineering at Meta https://engineering.fb.com/2026/10/19/data-center-engineering/inside-prometheus-meta-gigawatt-scale-supercluster/

**3. OpenAI：20 种语言从零写 SQLite，GPT-6 Astra 最大推理平均通过率 87.4%**  
10 月 19 日 OpenAI 公布两套自建评测，对象是公开代码和文档较少的语言，举例包括 COBOL、Fortran 和 Visual Basic。MultiLangBench 要求模型用指定语言从零实现一个与 SQLite 兼容的数据库引擎，共 **20** 种语言，用数据库文件对照参考 SQLite 的测试套件打分。厂方写，最大推理下 GPT-6 Astra 的平均测试通过率为 **87.4%**，GPT-5.6 Sol 为 **26.8%**；分语言包括 COBOL 从 **10.9%** 到 **72.1%**、OCaml 从 **25.6%** 到 **85.8%**、Fortran 从 **21.4%** 到 **83.5%**、Visual Basic 从 **27.5%** 到 **89.4%**。Astra 在 20 种里的 19 种高于 83%，COBOL 仍是最低的 72.1%。GPT-6 Luna 在同样的最大推理下平均 **40.3%**，厂方估算每条样本 API 成本 **$0.77**，对照 GPT-5.6 Sol 的 **$3.48**。另一套把 COBOL 迁到 C++、Java、Kotlin、Python 或 Rust，成功标准是隐藏测试全部通过、可观察输出逐字节一致。厂方写 GPT-6.1 Sol 在低推理下准确率 **86.6%**，同设置的 GPT-5.6 Sol 为 **5.4%**，API 成本为后者的 **61%**；更高推理达到 **97.9%**。这些是厂方评测，不是独立榜单。厂方称评测设置与测试集放在 GitHub。对还在维护 COBOL 或 Fortran 的团队，87.4% 是「从零写一个 SQLite」而不是「迁生产核心」；合同现在可以问引用的是 MultiLangBench 还是迁移评测，以及 97.9% 用的推理档。  
来源：OpenAI https://openai.com/index/low-resource-programming-languages/

**4. MiniMax 上线 M3.1 Flash：输入 $0.15、输出 $0.60 / 百万 token，权重稍后**  
10 月 19 日 MiniMax 宣布 M3.1 Flash 已在 MiniMax API、M Plan 和 MiniMax Code 上线，权重写明稍后放出。厂方称匿名运行过的 Space Bunny 是它的早期版本，期间处理超过 **200 万亿** token。标价为每百万 token 输入 **$0.15**、输出 **$0.60**、缓存输入 **$0.015**。厂方称相对前代，在线推理将近快 **3** 倍，智能体任务的使用成本低 **70%**；日常输出速度可以到 **200** token/秒以上，中位数 **170** 以上。同页给出的厂方分数包括 DeepSWE v1.1 **73.7%**、OSWorld V2 **61.7**、Agents’ Last Exam **29.6**、BankerToolBench **76.2**、CyberGym **82%**。厂方称在 OSWorld V2 和 ALE 上这组成绩居中国模型第一。这些都是厂方数字。近三日已写 DeepSeek-V4.1-Flash-1017 的价格和 DeepSWE；本条是另一家的标价和「权重还没放」的增量。对要换便宜编码代理的人，可对表的是 $0.15/$0.60 和 DeepSWE 的 73.7% 用的是哪套 harness；合同现在可以问线上 MiniMax-M3.1-Flash 是否已经切到这篇博文的检查点，以及权重许可证会不会是可商用的那种。  
来源：MiniMax https://www.minimax.io/blog/minimax-m31f

**5. Cloudflare 预览 Clairic：单次前向返回类型化的值，每百万输入 token $0.10**  
10 月 19 日 Cloudflare 在 Workers AI 上以预览放出抽取模型 Clairic，调用名为 `@cf/cloudflare/clairic`。它不逐 token 生成：一次前向从输入里抽出、算出或外推带类型的值，类型包括 text、number、date、list、estimate 和 forecast；对不上就返回 null，并带置信度。文本答案带字符偏移。文档页写上下文 **65,536** token，价格每百万输入 token **$0.10**，输出 token 计为 0。厂方称开放权重会在稍后放出，目前还没有。博客里的例子把邮件中的单价和税额在同一次前向里加成总额。对已经用大模型做 JSON 抽取的流水线，这是把「生成再解析」换成「类型约束的单次前向」的一个托管端点；合同现在可以问生产用的是这份预览，还是以后的开放权重，以及 $0.10 计的是 state token 还是把 schema 也算进 input。  
来源：Cloudflare Blog https://blog.cloudflare.com/clairic-extraction-model/ · Cloudflare Docs https://developers.cloudflare.com/workers-ai/models/clairic/

**模型 / 产品 / 政策**

- **模型/产品**：见要闻 3、4、5。另：10 月 19 日 Inception 宣布扩散语言模型 Mercury 3。厂方称参数规模超过 Mercury 1 的 **40** 倍，一组标准基准上的分数约为 Mercury 1（mini）的 **3** 倍，在 NVIDIA GPU 上速度 **1,068** token/秒；上下文 **100 万** token，Mercury 2.5 为 **26 万**。标价每百万 token 输入 **$0.20**、输出 **$0.70**，上线五折后为 **$0.10** / **$0.35**；厂方写缓存 token 按输入价优惠 **90%**。厂方称在一组基准上不低于 GPT-6 Luna 和 Claude Haiku 5.5，并在自有网页代理 harness 的 **50** 道 Mind2Web 任务上完成 **50%**，高于同设置的 GPT-6.1 Sol，但没有给出对照分数。这些是厂方数字。模型经 Inception API、OpenRouter、Baseten 和 Vercel 提供，接口与 OpenAI API 兼容。来源：Inception https://www.inceptionlabs.ai/blog/introducing-mercury-3
