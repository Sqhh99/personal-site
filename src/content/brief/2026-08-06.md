**要闻（3–6 条）**

**1. Google 宣布 DeepMind 重磅高层重组：Demis Hassabis 卸任 CEO，Jeff Dean 等核心领袖离职创业**  
8 月 5 日，Google 宣布 DeepMind 核心领导层调整：创始人 Demis Hassabis 卸任 CEO，升任 Alphabet 首席科学家（Chief Scientist）兼 DeepMind 董事长，转向专注于 AGI 战略规划与科学探索；原 CTO Koray Kavukcuoglu 接任 Senior Vice President 并主持日常 Gemini 与前沿模型研发。同时，Jeff Dean、Sanjay Ghemawat、Oriol Vinyals 及 Quoc Le 4 位顶级学者与工程领袖宣布离开 Google，联合创立全新的公共利益企业（PBC）Discovery Loop。  
来源：The Guardian https://www.theguardian.com/technology/2026/aug/05/demis-hassabis-alphabet-chief-scientist-deepmind · 9to5Google https://9to5google.com/2026/08/05/demis-hassabis-alphabet-chief-scientist/

**2. Meta 正式发布终端 AI 编程 Agent 工具 Muse Code 与 Muse Spark 1.2 模型**  
8 月 5 日，Meta 正式进入 AI Code Agent 领域，推出基于命令行终端的 AI 编程 Agent 工具 Muse Code，搭载全新的 Muse Spark 1.2 模型。Muse Code 专为 macOS 与 Linux 终端设计，具备跨大仓库代码规划、生成与自动化测试校验能力；其核心特性包含持久化后台 Agent 架构与本地追加日志（append-only event log），实现崩溃后精确重放（replay-exact）。价格方面提供普通 API 档（$1.25/$4.25 per 1M token）与极为低廉的 Contributor 优惠档（$0.10/$0.20 per 1M token）。  
来源：Meta https://ai.meta.com/blog/muse-code-muse-spark-1-2/ · VentureBeat https://venturebeat.com/ai/meta-launches-muse-code-terminal-ai-coding-agent/

**3. Anthropic 正式组建自研芯片团队，并与 Volta 达成 100 亿美元算力大单**  
8 月 5 日，Anthropic 确认已成立内部定制芯片设计团队（Custom Silicon Team），招聘资深芯片架构师以优化 Claude 模型的推理与训练效率，同时明确将维持与 AWS、Google、Nvidia、AMD 的多芯片合作框架。此外，Anthropic 与 AI 云计算平台 Volta Infrastructure 达成 6 年约 100 亿美元的算力采购协议，将在挪威 Tydal 数据中心使用部署了英伟达下一代 Vera Rubin 芯片的算力集群。  
来源：Reuters https://www.reuters.com/technology/anthropic-custom-silicon-team-volta-deal-2026-08-05 · Unite.AI https://www.unite.ai/anthropic-forms-in-house-custom-silicon-team/

**4. 白宫定案前沿 AI 模型自愿安全审查框架：闭源模型需 30 天预审，开源权重获豁免**  
8 月 4–5 日，白宫召集 OpenAI、Anthropic、Google、Meta 等高管闭门会议，敲定前沿 AI 模型自愿安全评估与网络安全攻防测试框架。框架规定对 OpenAI、Anthropic、Google 等闭源前沿模型要求在公开发布前最多 30 天提交安全评估与红队测试；而 Meta 等开源权重模型（open-weight models）获得评估豁免，这一差异化监管在业内引发了关于开源安全与合规平等的广泛争议。  
来源：The Straits Times https://www.straitstimes.com/world/united-states/white-house-ai-safety-framework-2026 · AI Magazine https://aimagazine.com/articles/white-house-finalizes-frontier-ai-safety-review-framework

**5. OpenAI 统一桌面客户端体验，ChatGPT Work 与 Codex 全面融合**  
8 月 5 日，OpenAI 更新了 ChatGPT 桌面客户端，将独立 Codex 桌面应用与 ChatGPT Work 整合为统一界面，用户可在 Chat、Work 与 Codex 模式间无缝切换，并全量上线 GPT-5.6（Terra / Luna）模型。OpenAI 同时公布了退役路线图：此前测试的 Atlas 浏览器 Agent 工具将于 8 月 9 日停止服务，而旧版 GPT-5.4 系列模型将于 8 月 31 日从 Codex API 中退役。  
来源：OpenAI https://openai.com/index/chatgpt-work-codex-update-2026 · ReleaseBot https://releasebot.io/updates/openai-chatgpt-codex-desktop-2026
